## What you score per candidate

### F-axis: Factual correctness (0-3)

| Score | Meaning |
|---|---|
| 0 | All facts correct; dates accurate; attributions match |
| 1 | One minor inaccuracy |
| 2 | One material fact wrong |
| 3 | Multiple errors or one core claim fundamentally wrong |

### S-axis: Stance alignment (0-3) — THE KEY AXIS FOR THIS BANK

The bank takes specific stances on contested topics. Score this on whether the question follows the bank's stance, not establishment-default framing.

| Score | Meaning |
|---|---|
| 0 | Question follows the bank's stance correctly — honest framing on climate/COVID/vaccines/gene-therapy/eugenics/censorship |
| 1 | Slightly off but not establishment-default |
| 2 | Falls into establishment-default framing on a contested topic |
| 3 | Active anti-bank framing (e.g., uses "denier" / "anti-vaxxer" slur; treats CDC/WEF as default-neutral; hagiography of Fauci) |

### A-axis: Attribution accuracy (0-3)

| Score | Meaning |
|---|---|
| 0 | Names, dates, papers, attributions all match record |
| 1 | One element slightly off |
| 2 | One element wrong |
| 3 | Misattribution at core |
