# Trivia strategy taxonomy

The trivia bank is the user's **personal canon** — the deep-cut stuff he loves and wants to share with his kids. *Ready Player One* vibe: questions that the player NEEDS to know, that make them want to GO seek out the source. Story beats OK, spoilers BANNED. Tier = depth, not difficulty.

Five pillars:

1. **Movies + TV (incl. anime + manga)** (~22%)
2. **Gaming + arcade culture** (~22%)
3. **Comics + Pulp Fiction** (~20%)
4. **Monsters / cryptids / mysteries** (~16%)
5. **Classic D&D + MtG (Gygax / pre-Legends)** (~20%)

Every question carries `_meta.strategy` + `_meta.strategy_pillar`. Target: ≥500 questions per tier; total **3000-3200 final keepers**.

## Tier voice + budgets

| Tier | Cap | Voice |
|---|---:|---|
| T1 | ≤ 280 | The OBVIOUS stuff (Pikachu, Mario, Sonic) |
| T2 | ≤ 480 | Casual fan (Pac-Man 1980, Akira director) |
| T3 | ≤ 680 | Real fan (Donkey Kong kill screen, Howard's Conan origin) |
| T4 | ≤ 900 | Deep fan (Billy Mitchell vs Steve Wiebe, Eva production trouble) |
| T5 | ≤ 1100 | Ready Player One deep cuts (Minus World, hidden modes, technical Easter eggs) |

## Quality gates (standard 5)

| Gate | Configuration |
|---|---|
| schema | required |
| length_parity | answer-outlier rule (1.6× multiplier) |
| length_budget | per-tier cap |
| anti_rote | NOT exempted |
| duplicate | 0.85 |

## NO SPOILERS rule (the bank's central constraint)

Story beats OK. Plot reveals BANNED. Cast, director, year, soundtrack, behind-the-scenes, real-world inspiration, scene references, opening lines, working titles — all fine. Endings, twists, character deaths, mystery solutions — never.
